### 本版重点 / Highlights

0.15.0 把 Cowork 从“能展示任务过程”的对话模式，推进为可用于真实项目工作的执行模式。Agent 现在能在授权范围内检查工作区、检索和修改代码、运行命令与测试，并把文件、命令、Patch 和 Git 证据保留在同一条任务链里；用户不再只能看到一段最终文字，而是能判断它实际做了什么。

这版也补上了长任务最容易出问题的部分：每次运行都有独立身份、事件顺序和检查点。切换会话、重载引擎或恢复任务时，旧事件不会覆盖新任务；可安全恢复的检查点可以续跑，不能可靠恢复的协作状态会明确说明原因，而不是假装成功。

界面交付同样做了收口。模型文字、工具卡片和公开进度按真实时间顺序呈现；最终答复不会重复，生成的 HTML 等文件会附在对应答复中；任务完成后，后台 checkpoint 和协调收尾仍保留给恢复与审计，但不再淹没聊天主线。

### 更新内容 / What's New

🧑‍💻 **Cowork Coding 工作流** — Agent 支持在项目工作区内检查、检索、编辑/应用 Patch、运行命令与测试，并提供 Git status/diff 等验证证据，形成“理解 → 修改 → 验证 → 交付”的闭环。

🧭 **可恢复的任务运行** — 引入 run 级状态、事件序号与持久化检查点；旧运行、重复事件和后台会话不再覆盖当前任务，安全条件满足时可从检查点继续。

🤝 **真正的多智能体协作** — 计划节点可获得前序结果，子智能体继承项目、模型和权限上下文；顶层任务会等待协作结果收拢，并对超时、取消和孤儿任务进行明确处理。

🛡️ **逐调用审批与写入保护** — 高风险工具按完整调用内容逐次授权；写入、编辑与删除增加内容校验、原子替换和竞态保护，避免外部修改被意外覆盖。

🕒 **按真实顺序呈现任务过程** — 正文、公开进度和工具卡片在同一时间线交错显示，历史重开后也保持原顺序；阶段动画仅保留真正进行中的一项。

📎 **最终答复与文件合并交付** — 已流式展示的最终答复不会在完成时重复出现；HTML 等生成文件与校验信息附在同一条答复中，便于查看和下载。

💬 **更克制的思考与收尾显示** — “正在思考”只在真实等待模型输出时短暂呼吸显示；任务结束后隐藏聊天主线中的后台收尾噪音，同时保留其恢复与审计价值。

🔌 **MCP 配置与远程连接优化** — 支持更多官方配置包装格式，区分 HTTP 与 SSE 连接；远程 MCP 可安全跳转浏览器完成登录或 OAuth，配置页面和编辑入口更简洁。

⚙️ **设置与维护入口收敛** — 模型/联网、已归档对话、应用/维护重新分组，减少配置查找成本。
